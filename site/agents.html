Shrooms Agents

Your coding agents, on your own machines, from your phone.

Why it belongs next to shrooms

You leave Claude Code working on the laptop, or on a box at home, and walk away. Then it stops to ask whether it may run something — and you are not there. Shrooms Agents puts those sessions on your phone and in Basecamp: you see the reply as it is written, allow what it wants to run, answer its questions, send it a photo or a voice note.

shrooms is what makes that simple. Your machines are already on one mesh, so the phone reaches the laptop wherever both are — no port forwarding, no cloud relay, no account, no tunnel service. And the mesh is the lock: the agent listens only on mesh addresses, so only your own devices can reach it.

What it does

  • Every session on every machine, in one list — the ones you star first. Live replies, search across a whole conversation, and notifications when one needs you.
  • Prompts and questions: allow or deny what it wants to run, or auto-approve a session; pick an answer when it asks.
  • Files and voice notes, transcribed on your own machine (Parakeet) — no audio goes to a speech service.
  • Take over a terminal's session and carry on from the phone.
  • Claude Code or pi — pi on any model, a local one included, so a machine with no Claude account can serve sessions too. More can be plugged in (how).

Install

On each machine that runs coding agents — shrooms already installed there:

curl -fsSLO https://raw.githubusercontent.com/vpavlin/shrooms/master/scripts/install-agent.sh
sudo bash install-agent.sh --voice

It takes the agent from the shrooms image, runs it as you (never as root), opens it to the mesh only, and with --voice sets up voice notes. Claude Code and pi are your own, logged in as in a terminal. --uninstall takes it all away again.

On the phone, Shrooms Agents is an Android app beside shrooms — open it from the "agents" link in the shrooms app. In Basecamp, the shrooms_agents module. Neither is in a public store yet: AGENTS=1 scripts/build-apk.sh and make basecamp-agents-lgx.

One person's mesh. Every device on the mesh can drive the agents on it, and an agent can do whatever its user can. That is right for your own devices — run it only on a mesh where every member is you.

How it works, the API and the limits: docs/agents.md · why it is a separate app: ADR-036.
